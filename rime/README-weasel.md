# RIME / Weasel variant

The same idea as the standalone prototype, but inside a real Windows IME:
[Weasel (小狼毫)](https://rime.im) runs the schema, and a Lua filter re-ranks candidates
with the character n-gram model. No LLM in this variant.

```
keystrokes ──► speller ──► script_translator (luna_pinyin)  ─┐
                       ├─► table_translator  (en_words)      ├─► trilingual_rank.lua ──► candidates
                       └─► table_translator  (sv_words)      ┘        │
                                                          langid_model.lua (naive Bayes over 1-4 char-grams + whole word)
                                                          + previous commit as context
                                                          + "sv_hint" if a physical å/ä/ö key was pressed
```

* `trilingual.schema.yaml` – pinyin + EN + SV dictionaries in parallel.
* `lua/trilingual_rank.lua` – ranks by language probability; keeps one candidate of each
  other language near the top; offers the raw typed word when it is in no dictionary.
* `lua/trilingual_keys.lua` – folds å/ä/ö keys into a/a/o; punctuation follows the previous word.
* `lua/langid_model.lua` – generated by `train/train_langid.py` (same model as the prototype).
* `en_words.dict.yaml`, `sv_words.dict.yaml` – generated by `train/build_dicts.py`.

Install (this changes Windows input settings — adds the Weasel IME):

```powershell
winget install Rime.Weasel
powershell -ExecutionPolicy Bypass -File rime\install_weasel.ps1
```

Then switch to the 中英瑞 schema with Ctrl+` or F4. Set `trilingual/show_confidence: true`
in the schema to see e.g. `en 87%` on the first candidate while tuning.
